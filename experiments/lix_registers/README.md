# LIX across Hungarian registers, and the interpretation bands

Two questions the threshold study left open.

**Does the threshold hold outside web and news?** Every corpus in the calibration is a web
crawl or a news wire, yet every caveat it ships tells the reader that a threshold belongs to a
register and must be rechecked on their own texts. The study never did that itself. This runs
the same measurement on parliamentary speech, corruption journalism and song lyrics.

**What does a Hungarian LIX score mean?** `LixResult.band` returns `None` away from
Björnsson's 6, because the labels were fitted to Swedish prose. The calibrated threshold
therefore buys a number that is comparable between Hungarian texts and interpretable as
nothing. The band mapping here is the same equipercentile argument as the threshold, one level
up: find the Hungarian score that sits where each Swedish boundary sits.

## How to run

```bash
# Uses only corpora download_data.py fetches. This is what a clean checkout can run.
uv run python experiments/lix_registers/scripts/run.py --tier1-only

# Adds the author-local registers, if they are present.
uv run python experiments/lix_registers/scripts/run.py --corpus-root ~/projects
```

Both forms produce a complete record. The tier-1 form is the one that has to keep working.

## The enabling detail

The Leipzig archives the calibration already downloads carry a `-sentences.txt` beside the
`-words.txt` the study has always read: a million sentences each, `id`-tab-text, UTF-8. That
is what makes a *real* LIX possible on both sides. Until now the Swedish reference had no LIX
score at all — only a word-length curve — so there was nothing to map bands from.

`experiments/lix_calibration/scripts/running_text.py` is the reader.

## Two tiers, and why the distinction is published

**Tier 1 — public.** Leipzig Swedish and Hungarian news. Fetched by `download_data.py`,
reproducible by anyone.

**Tier 2 — author-local.** Parliamentary speeches (parlamonitor), corruption journalism
(kmdb_dashboard), song lyrics (music_networks). These live in sibling projects on one machine.
They are not redistributable and the paths are not guessable, so each is opt-in via
`--corpus-root`, is skipped with a log line when absent, and carries its tier in every row of
the output. The numbers are published; the corpora are not.

## Where *B* comes from, and why it is a column

LIX implementations disagree almost entirely on the sentence count. A panel that silently
mixed corpus-supplied sentence counts with a segmenter's would be measuring the segmenter as
much as the register. So every row declares its `sentence_source`:

| register | *B* from |
|---|---|
| `leipzig-swe-news`, `leipzig-hun-news` | the corpus (one sentence per line) |
| `parlamonitor` | the corpus (each record carries a `sentences` list) |
| `kmdb` | **segmented** — read from SQLite, which has no sentence boundaries |
| `lyrics` | **segmented**, and weakly so — lyrics have line breaks, not sentences |

The `kmdb` token Parquet does carry a real `sent_idx`, but reading it would need pyarrow — a
large dependency for one row of a panel. The consequence is stated rather than hidden.

For `lyrics`, read the mean sentence length as "words between things the splitter took for a
full stop", not as a sentence length.

## What the sentence sample is and is not

Leipzig collections are sampled and deduplicated, so there are no documents and no discourse
order. Both LIX terms are ratios — mean sentence length, long-word share — and a random
sentence sample estimates both without bias, so **the point estimates are sound**.

What is not sound is treating a window of sentences as a document. Windows drawn from shuffled
sentences are more alike than real texts are, so the spread is too narrow, and the effect is
worst in the tails where the outer band boundaries sit. Both languages get identical
treatment, which is what equipercentile matching needs — but a claim about absolute spread
does not survive, and that is why the mapping is recomputed across a ladder of window lengths.
A boundary that moves with the window is telling you about the window.
